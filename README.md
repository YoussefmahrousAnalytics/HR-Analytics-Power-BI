
# Telecom Network Performance Analytics

## Project Overview
This project analyzes telecom network performance, service quality, incidents, and maintenance operations using SQL Server and Power BI.

The goal is to identify network performance issues, compare regional service quality, analyze incident severity and resolution time, and evaluate maintenance costs and downtime.

## Tools & Technologies
- SQL Server
- SQL (Data Analysis & Views)
- Power BI
- DAX Measures
- Data Modeling & Relationships
- Interactive Dashboards

## Dataset
The dataset covers 120 telecom towers over 90 days, from January 1 to March 31, 2026.

Main data tables:
- Tower
- Network_KPI
- Incidents
- Maintenance
- Date
- Customer_Complaints_Import

## SQL Analysis
- Regional network performance analysis
- Average download and upload speed
- Network availability and latency
- Dropped calls analysis
- Incident severity and resolution time
- Maintenance cost and downtime
- Regional customer complaint analysis

## Power BI Dashboard

### 1. Network Performance Overview
- Total Towers
- Average Network Availability
- Average Download Speed
- Total Dropped Calls
- Download speed comparison by region
- Latency comparison by region
- Interactive region and date slicers

### 2. Incident & Maintenance Analysis
- Total Incidents
- Incidents by Severity
- Average Incident Resolution Time by Region
- Total Maintenance Cost by Region
- Maintenance Downtime by Region
- Interactive filters for region and date
