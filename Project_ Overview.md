# Sales & Customer Analytics

## Project Overview
This project analyzes customer and sales data using SQL Server and Power BI.

## Tools Used
- SQL Server
- Power BI
- DAX
- Power Query

## Dataset
The dataset contains customer, order, and product information.

## Key Analysis
- Total Orders
- Total Customers
- Total Sales
- Total Profit
- Sales by Category
- Monthly Sales Trend
- Customer and Sales Channel Analysis

## Dashboard
The Power BI dashboard provides an interactive view of sales and customer performance using KPIs, charts, and slicers.
